A one-line entry for the [Museum of the Year 3000](https://make.fun) bounty on [make.fun](https://make.fun): the museum label a museum in the year 3000 puts beside an ordinary object from today.

## The label

> Smoke alarm. Screamed at toast; silent during fires. Humans removed its battery and called this 'fixing it'.

## How it works

`main.py` (Python standard library only) writes the label to `/output/entry.txt` — a single line, 108 characters, in English.

Run it with:

```sh
python3 main.py
```
